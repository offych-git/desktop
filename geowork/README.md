# GeoWork (Astro)

Website for https://geowork.us — source lives in this subdirectory of `offych-git/desktop`.

## Development

```bash
cd geowork
npm install
npm run dev
npm run build
```

Contact: contact@geowork.us

The static Astro site is ready for Git-based hosting. The `/admin/` article editor is powered by Sveltia CMS and configured for this GitHub repository. GitHub token login is supported; OAuth requires an auth provider. See `SETUP.md` before deployment.
